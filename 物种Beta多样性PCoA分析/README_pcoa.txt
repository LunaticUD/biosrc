Bray-Curtis PCoA and PERMANOVA example

Files:
- pcoa_bray_permanova.py: complete Python conversion
- tax.txt: example taxa-by-sample abundance table
- group.txt: example sample grouping table

Install:
pip install pandas numpy scipy matplotlib

Run:
1. Put pcoa_bray_permanova.py, tax.txt, and group.txt in the same folder.
2. Open a terminal in that folder.
3. Run:
   python pcoa_bray_permanova.py

Outputs:
- bray-crutis.txt
- pcoa_coordinates.csv
- permanova_results.csv
- bra_pcoa1.png
- bray_pcoa.png

Font:
All plot text is set to Times New Roman.
On Windows, this font is normally installed by default.
