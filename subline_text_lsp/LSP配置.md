# Subline Text Lsp 配置
## 为了更方便的结合AI进行日常工作，我需要功能简单直接的不太繁琐的编辑器，这里选用了Subline Text，方便快捷
1. 下载便携版Subline Text，网上可以找到注册软件的方法，这里就不提供了
2. 安装配置界面和字体（Maple Mono NF CN）
3. 安装Package Control来安装插件LSP、LSP-basepyright、LSP-R、和Terminal，以及中文
	首先安装Package Control
	安装中文界面、LSP、...
	配置LSP
	安装Terminal终端并配置设置和快捷键
4. 测试python和R
