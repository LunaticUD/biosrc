Python alpha-diversity example

Files:
- alpha_diversity_analysis.py: complete Python conversion
- tax.txt: example taxa-by-sample count table
- group.txt: example sample grouping table

Required packages:
pip install pandas numpy scipy matplotlib

Run:
1. Put the three files in the same folder.
2. Open a terminal in that folder.
3. Run:
   python alpha_diversity_analysis.py

The script generates:
- alpha_indices.csv
- alpha_indices_long.csv
- spe_alpha_1.png
- spe_alpha.png

Font:
All chart text is configured as Times New Roman.
On Windows, Times New Roman is normally available by default.
